# 🎯 Phase 1: DOM Selection

---

## 🧠 Goal
Learn how to correctly select elements from the DOM using JavaScript,
and understand the differences between selection APIs.

---

## 🔑 Key Concepts
- Single vs multiple selection
- Node vs Element
- Live vs static collections
- CSS selector-based selection

---

## ⚠️ Common Mistakes
- Assuming all selectors return arrays
- Forgetting that some collections are live
- Using the wrong selector for the job

---

## ✅ Best Practices
- Prefer `querySelector` / `querySelectorAll`
- Understand what your selector returns
- Always handle `null` safely

---

## 🚀 Why This Matters
Frameworks rely on predictable DOM selection logic.
Mastering this makes UI logic stable and debuggable.
