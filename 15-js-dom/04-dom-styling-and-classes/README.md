# 🎨 Phase 3: DOM Styling & Classes

---

## 🎯 Goal
Learn how to style DOM elements correctly using JavaScript
without breaking maintainability or performance.

---

## 🧠 Key Concepts
- Inline styles vs CSS classes
- element.style limitations
- classList API
- Dynamic UI states

---

## ⚠️ Common Mistakes
- Using element.style everywhere
- Hardcoding colors in JavaScript
- Overwriting styles unintentionally

---

## ✅ Best Practices
- Use CSS classes for styling
- Use JavaScript only to toggle states
- Separate logic from presentation
