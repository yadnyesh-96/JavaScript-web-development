# 🧠 Phase 2: DOM Content & Attributes

---

## 🎯 Goal
Understand how content and attributes work in the DOM,
and avoid common bugs and security issues.

---

## 🔑 Key Concepts
- Text nodes vs HTML nodes
- textContent vs innerHTML vs innerText
- Attributes vs properties
- data-* attributes (dataset)

---

## ⚠️ Common Mistakes
- Using innerHTML when textContent is safer
- Confusing attributes with properties
- Creating XSS vulnerabilities unknowingly

---

## ✅ Best Practices
- Prefer textContent
- Use innerHTML only when required
- Understand what comes from HTML vs DOM
