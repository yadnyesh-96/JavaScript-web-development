# **JavaScript** ⛺
### **What is JavaScript ?**
JavaScript is **server** and **client** side programming language. It is used for developing the client side as well as a sever side application with the node js.

---
### **What is client side programming ?**
A programming language which can execute on a client or need application to execute a program called as client sied programming.

--- 
### **What is server side programming ?**
Programming language can execute its program on server called as server side programming language.
